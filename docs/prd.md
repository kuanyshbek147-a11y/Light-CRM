# PRD: WhatsApp CRM MVP

## Problem
Sales teams lose leads in personal chats, miss response SLAs, and cannot track manager performance.

## Goal
Provide one web workspace where all client conversations are handled, linked to deals, and measured.

## Roles
- Owner/Admin: manages users, sees team KPI.
- Manager: handles conversations and deals.

## Core User Scenarios
1. Incoming message appears in inbox.
2. Manager responds and assigns contact to a deal stage.
3. Team lead tracks first response time and throughput.

## MVP Scope
- Unified inbox with search and filters.
- Conversation view with outgoing messages.
- Contact card + deal card.
- Deal pipeline stage updates.
- Dashboard with basic KPI.
- Auth and role-based access.
- Simulator for incoming WhatsApp events.

## Out of Scope
- Real WhatsApp Business API integration.
- Billing and subscriptions.
- Advanced automations.
