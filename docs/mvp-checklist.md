# MVP Checklist

- [ ] Auth works for admin and manager accounts.
- [ ] Inbox lists conversations with search/filter.
- [ ] Manager can send a message in conversation.
- [ ] Deal is linked to conversation and stage can be changed.
- [ ] Dashboard shows first response time, handled conversations, sent messages.
- [ ] Simulator creates incoming messages every interval.
- [ ] App starts with `docker compose up`.
- [ ] Seed data is loaded automatically.
