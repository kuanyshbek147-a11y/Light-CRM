# Light CRM

**Light CRM** — веб-приложение для работы с клиентскими диалогами из **WhatsApp** и **Telegram** в одном окне: входящие сообщения, ответы менеджера, карточка клиента, фильтры по когортам, скрипты ответов и обзор воронки с KPI.

---

## Возможности

| Область | Описание |
|--------|----------|
| **Единый inbox** | Все диалоги в одном списке с поиском и фильтрами |
| **Каналы** | Поддержка WhatsApp (демо + симулятор) и Telegram (бот) |
| **Карточка клиента** | Имя, телефон, город, причина обращения, тип клиента, категория |
| **Когорты** | Фильтрация по полям карточки для сегментации |
| **Скрипты ответов** | Библиотека шаблонов, переменные `{name}`, `{city}`, `{phone}` и др. |
| **Воронка и KPI** | Сделки, стадии, базовые метрики по активности |

---

## Технологии (MVP)

- **Frontend:** React, TypeScript, Vite  
- **Backend:** Node.js, Express, PostgreSQL  
- **Realtime:** Socket.IO  
- **Контейнеры:** Docker Compose
