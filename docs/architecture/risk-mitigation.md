# Сложные моменты и mitigation plan

## 1. Менеджмент состояния на фронтенде
- Риск: разрастание `App.tsx` и хаотичные эффекты.
- Митигирование:
  - вынос API-конфига и запросов в `shared`;
  - постепенный перенос экрана в feature-модули;
  - кэш-запросы и инвалидация по событиям.

## 2. Сложные фильтры и производительность
- Риск: тяжелые SQL и деградация листингов.
- Митигирование:
  - унифицированный объект фильтра;
  - обязательные составные индексы;
  - пагинация и ограничение диапазонов.

## 3. Консистентность KPI
- Риск: расхождения между онлайн-расчетом и отчетами.
- Митигирование:
  - единая методика KPI;
  - snapshot-таблицы для периодов;
  - smoke-проверка формул на seed-данных.

## 4. Интеграции и гонки событий
- Риск: дубликаты и рассинхронизация статусов.
- Митигирование:
  - idempotency keys;
  - дедупликация по external id;
  - retry policy и журнал delivery-ошибок.

## 5. Регрессии при быстрых изменениях
- Риск: ломаются ключевые бизнес-флоу.
- Митигирование:
  - smoke-тесты для health/auth/conversations/deals;
  - staging rollout;
  - чеклист релиза и rollback-план.
