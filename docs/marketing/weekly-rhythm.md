# Недельный ритуал продаж (4 недели) — вести в Light CRM

Цель: **3–5 платящих** за 30–45 дней.  
Оффер и цена: [offer-and-pricing.md](./offer-and-pricing.md)

## Воронка сделок в Light CRM
Создайте (или переименуйте) стадии под GTM:

| Стадия | Когда |
|--------|--------|
| `Лид` | Написали / ответили |
| `Демо` | Назначено или проведено демо |
| `Пилот` | Идёт пилот 14 дней |
| `Оплата` | Выставлен счёт / ждём перевод |
| `Клиент` | Оплатил (won) |
| `Отказ` | Явный отказ с причиной (lost) |

Каждый лид = сделка с названием компании + канал касания в комментарии/карточке.

## Ежедневно (пн–сб)
- [ ] **10–15** новых холодных касаний ([icp-lists.md](./icp-lists.md) / CSV)
- [ ] Ответить всем, кто ответил вчера (дожать до слота демо)
- [ ] Обновить стадии сделок в CRM
- [ ] Если есть пилот: короткий check-in по графику (день 3 / 7)

**KPI дня:** касания сделаны; воронка актуальна.

## Еженедельно (воскресенье или понедельник)
| Метрика | Норма |
|---------|--------|
| Новые целевые диалоги | ≥20 |
| Демо | ≥5 |
| Активные пилоты | ≥2 |
| Оплаты (накопительно к неделе 4) | → 3+ |

Краткий разбор: какой канал дал демо (тёплый / холодный / чат / партнёр) — усиливать его.

## Календарь 4 недель

### Неделя 1
- [ ] Оффер и цена зафиксированы (уже в docs)
- [ ] Заполнены **30 тёплых** в [icp-warm-template.csv](./icp-warm-template.csv)

### Неделя 2
- [ ] +70 холодных касаний
- [ ] **5 демо**
- [ ] Дожать пилоты недели 1 (день 7)
- [ ] **1 партнёр** (SMM / веб) с устным % или бесплатным кабинетом

### Неделя 3
- [ ] Закрытие первых оплат (день 14 пилотов)
- [ ] 1 короткий кейс «до/после» (даже внутренний)
- [ ] Усилить лучший канал касаний

### Неделя 4
- [ ] Повтор касаний тёплых отказов
- [ ] Цель: **≥3 оплаты** суммарно
- [ ] Список причин отказов (для следующей итерации оффера)
