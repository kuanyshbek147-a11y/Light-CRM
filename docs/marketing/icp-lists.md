# ICP-списки: тёплые и холодные

Шаблон для ручного заполнения. Цель недели 1: **30 тёплых** + старт **100 холодных** (набирать постепенно, 10–15 касаний/день).

Квалификация ICP (все «да»):
- [ ] Пишут клиентам в WA/IG каждый день
- [ ] ≥2 человека отвечают клиентам
- [ ] Болит: теряют лиды / нет истории / нет контроля / хаос в личных телефонах

Сегменты приоритета: авто / клиники / курсы / beauty / недвижимость / локальный e-com (Казахстан).

### Черновик тёплого сообщения
```
Привет, [Имя]! Делаю Light CRM — одно окно для WhatsApp/Instagram продаж.
Ищу 2–3 команды на пилот 14 дней (подключаем под ключ).
У вас сейчас переписки в личных телефонах менеджеров или уже сводите в одно место?
Могу показать 20 минут — или кинь 1–2 контакта собственников, у кого хаос в чатах.
```

### Черновик холодного сообщения (4–6 строк)
```
Здравствуйте! Пишу по продажам в WhatsApp/Instagram.
У многих команд вроде вашей лиды теряются между менеджерами в личных чатах.
Мы делаем Light CRM — все переписки в одном окне + кто ответил и как быстро.
Можно 15–20 минут показать на вашем кейсе на этой неделе?
Если не актуально — скажите, не буду беспокоить.
```

### Норма в день
- **10–15** новых холодных касаний
- Не спамить чаты тысячами — качество важнее объёма
