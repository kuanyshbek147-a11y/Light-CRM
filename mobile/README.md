# Light CRM — приложение для Android и iPhone

Одно приложение на **Capacitor 6** для обеих платформ. Внутри открывается рабочий кабинет
https://light-crm-kz.netlify.app, поэтому всё новое на сайте сразу появляется в приложении.

## Два вида интерфейса

Кнопка в шапке переключает вид, выбор запоминается на устройстве:

- **Как WhatsApp** — только список чатов и переписка: зелёная шапка, бежевый фон, зелёные исходящие сообщения.
  Для менеджеров, которым нужны только ответы клиентам.
- **Полная CRM** — меню, воронка, задачи, клиенты, аналитика.

На телефоне простой вид включается ещё и в «Профиль → Простой вид».

## Android

APK собирается сам в GitHub Actions (workflow **Android APK**) при изменениях в `mobile/`
или вручную: Actions → Android APK → Run workflow. Файл лежит в Artifacts → `LightCRM-android`.
Это отладочная сборка: её можно поставить на телефон напрямую (разрешить установку из неизвестных источников).

Локально на Windows: `npm run android:apk` из корня (нужен Android Studio).

## iPhone

См. [IOS.md](IOS.md): собрать можно только на Mac с Xcode.

## Публикация в магазинах

Нужны аккаунты разработчика владельца:

- **Google Play Console** — разовый взнос $25. Для релиза нужна подписанная release-сборка (AAB) с ключом подписи.
- **Apple Developer Program** — $99 в год, сборка и отправка в App Store / TestFlight через Xcode на Mac.
